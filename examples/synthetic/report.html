4. 评分卡

把 WOE 逻辑回归换算为评分卡：PDO、base score、base odds，每个变量每个分箱的分数，以及分数分布。

4.1 PDO 换算

PDO / base score / base odds
20 / 600 / 20:1
Factor = PDO / ln2
28.8539
Offset = base − Factor × ln(odds)
600 − 28.8539 × ln(20) = 513.5614
LR 截距 b0
-0.9777
基础分 = Offset − Factor × b0
541.77 → 取整 542
分箱分数
points = −Factor × 系数 × WOE，取整
可能的分数范围
444 ~ 642
整数分数的 AUC（test / OOT）
test 0.7734 / OOT 0.7672
